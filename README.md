# NFC-Link
NFC Link membantu kamu membagikan profil WhatsApp, Instagram, TikTok, DANA, Facebook, dan lainnya hanya dengan satu tempelan. Aktifkan atau matikan tautan sesuai keinginan, ganti foto profil dengan sekali ketuk, dan tulis ke tag NFC agar orang lain bisa langsung membuka profilmu tanpa mengetik apa pun.
